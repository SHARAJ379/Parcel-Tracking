Authentication

Send the API key in the x-api-key header. Read keys can retrieve parcels and use the assistant. Write keys can create parcels, update status, and manage webhooks. Never put a key in browser code or a public repository.

curl -H "x-api-key: YOUR_API_KEY" \
  https://your-app.example/api/v1/parcels/DEMO-PARCEL-001

Create a parcel POST · 201

Creates a parcel and its initial timeline event.

curl -X POST https://your-app.example/api/v1/parcels \
  -H "x-api-key: YOUR_WRITE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tracking_id":"DEMO-NEW-001","destination":"London","eta":"2026-12-01T10:00:00Z"}'

Get tracking details GET · 200

Returns an owner-scoped parcel and its timeline in chronological order.

curl https://your-app.example/api/v1/parcels/DEMO-PARCEL-001 \
  -H "x-api-key: YOUR_READ_KEY"

Update parcel status PATCH · 200

Updates status and appends a timeline event. Valid statuses: created, picked_up, in_transit, out_for_delivery, delivered, delayed, failed_delivery.

curl -X PATCH https://your-app.example/api/v1/parcels/DEMO-PARCEL-001/status \
  -H "x-api-key: YOUR_WRITE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"status":"in_transit","location":"Sorting facility"}'

Parcel assistant POST · 200

Ask a question based only on the requested parcel’s records. Questions are limited to 1,000 characters.

curl -X POST https://your-app.example/api/v1/assistant \
  -H "x-api-key: YOUR_READ_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tracking_id":"DEMO-PARCEL-001","question":"What is the latest update?"}'

Webhooks

Register HTTPS endpoints, list the owner’s endpoints, or delete an endpoint by ID. The registration response includes its signing secret once.

curl -X POST https://your-app.example/api/v1/webhooks \
  -H "x-api-key: YOUR_WRITE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/webhooks/parcels"}'

curl https://your-app.example/api/v1/webhooks \
  -H "x-api-key: YOUR_READ_KEY"

curl -X DELETE https://your-app.example/api/v1/webhooks/WEBHOOK_UUID \
  -H "x-api-key: YOUR_WRITE_KEY"

Verify delivery signatures

Compute HMAC-SHA256 over the exact UTF-8 request body using the webhook secret. Compare it with X-Signature: sha256=<lowercase-hex-digest>. Do not parse and re-serialize the body first.

Responses and errors

{"success":true,"data":{"tracking_id":"DEMO-PARCEL-001"}}
{"success":false,"error":{"code":"parcel_not_found","message":"No parcel matches that tracking ID."}}
  • 400 Invalid input or webhook URL
  • 401 Missing or invalid API key
  • 403 API key lacks the required scope
  • 404 Parcel or webhook not found
  • 409 Tracking ID already exists
  • 429 Rate limit or assistant quota reached
  • 502 / 504 Assistant upstream error or timeout
