API guide

Send API keys in the x-api-key header. The public page does not expose API keys.

FastAPI documentation remains available at /docs.

Create parcel

POST /api/v1/parcels
x-api-key: <write-key>
{"tracking_id":"TEST-001","destination":"London","eta":"2026-12-01T10:00:00Z"}

Update status

PATCH /api/v1/parcels/TEST-001/status
x-api-key: <write-key>
{"status":"in_transit","location":"Sorting facility"}

Assistant

POST /api/v1/assistant
x-api-key: <read-key>
{"tracking_id":"DEMO-PARCEL-001","question":"Where is my parcel?"}

Webhook

POST /api/v1/webhooks
x-api-key: <write-key>
{"url":"https://example.com/webhook"}

Verify the exact request body with HMAC-SHA256 using X-Signature: sha256=<hex-digest>.

Errors

Responses use {"success":false,"error":{"code":...,"message":...}}. Status codes include 400, 401, 403, 404, 409, 429, 500, 502 and 504.
